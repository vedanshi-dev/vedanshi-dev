# 🧠 My Learning Philosophy

I don't want my learning to be:

```text
Learn → Memorize → Exam → Forget ❌
```

I want it to be:

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Build
  ↓
Make Mistakes
  ↓
Improve
  ↓
Repeat
```

Whenever I learn something new, I try to ask:

> ❓ Why does it work?
> ❓ How does it work?
> ❓ Can I implement it myself?
> ❓ Can I solve a problem using it?
> ❓ What happens if I change something?
